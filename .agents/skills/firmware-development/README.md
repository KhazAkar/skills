# firmware-development

Build embedded firmware in C, C++ or Rust safely and reproducibly. Know the
silicon before coding, pin the toolchain, test on the host and in an emulator,
flash with backup and verification, with lode-programming loaded from the
start so every phase writes its lode/ files and ADRs as it happens.
