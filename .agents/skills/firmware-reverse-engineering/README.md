# firmware-reverse-engineering

Reverse-engineer embedded/firmware targets safely and methodically. The three pillars are: back up everything before all else, research datasheets/erratas (converting PDFs to markdown and grepping around) to understand the hardware, and document the whole effort with the lode-programming methodology so the `lode/` folder stays current.
