# firmware-reverse-engineering

Reverse-engineer embedded/firmware targets safely and methodically. The two pillars are: back up everything before all else, and research datasheets/erratas (converting PDFs to markdown and grepping around) to understand the hardware. The whole effort is documented with the lode-programming methodology as the backbone, so the `lode/` folder stays current.
