# Shared cross-skill references
This folder holds reference material shared by more than one skill.
Promotion rule (2+): a topic moves here from a skill's `refs/` when a
second skill needs it, keeping provenance back to the origin skill.
Currently: firmware references shared by firmware-reverse-engineering
and firmware-development, plus the LodeStack OSMM and AMDD mappings
used by the lodestack-* contracts.
Rule: link, never copy.
