Reverse engineering follows this cycle:

- TASK
- MODEL
- PROBE
- PROOF

For cycles which will involve code editing, it looks like this:

- TASK
- MODEL
- PROBE
- EDIT
- PROOF

'Hot' loop is MODEL - PROBE - EDIT - PROOF, until TASK resolves as NEGATIVE or POSITIVE for code-editing enabled flow

for non code-editing flow:

'Hot' loop is MODEL - PROBE - PROOF, until TASK resolves as NEGATIVE or POSITIVE.
